# 百度百科熊猫星图 · 多轮核验计划

对已入库的 `百度百科熊猫星图4.md`～`22.md` 逐卷核验实体/关系覆盖，对齐「熊猫资料」金标准档案质量（`熊猫资料.md` / `熊猫资料2.md` / `熊猫资料3.md`）。

## 原则

- 以 **原文应有字段必须尽量抽到** 为准；原文未写不要求补全
- 谓词规范对齐 `tools/panda_history_extractor.py` 的 `profile_mode` 清单
- 默认 **缺口补抽** 后增量写入 Neo4j（不加 `--clear`）
- 单卷缺口个体占比 ≥ 40% 时整卷重抽再增量合并

## 三轮核验

1. **Round1 结构**：条目数对齐、统称主语、空 evidence
2. **Round2 覆盖（主轮）**：谱系号/性别/出生/父母/昵称/子女/迁居/逝世等原文应有维度  
   - 达标：个体覆盖率 ≥ 90%，且硬字段（谱系号/父母/出生时间）缺口 = 0
3. **Round3 抽检**：抽样父母关系本地校验 + 可选 `neo4j_qa`；扫描非规范谓词

## 命令

```bash
# 启发式冒烟（星图4 + 金标准 MD）
python scripts/verify_starmap_daily.py --self-check

# 进度
python scripts/verify_starmap_daily.py --status

# 只审计 Day1
python scripts/verify_starmap_daily.py --day 1 --skip-qa

# 审计 + 缺口补抽写库
python scripts/verify_starmap_daily.py --day 1 --fix

# 预览补抽
python scripts/verify_starmap_daily.py --day 1 --fix --dry-run

# 重试 needs_fix / failed
python scripts/verify_starmap_daily.py --retry --fix
```
