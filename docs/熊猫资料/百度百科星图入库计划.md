## 说明

- 每日命令会把当天分卷按「每片约 5 只熊猫」拆分后再抽取，避免整卷过长导致模型截断失败。
- 进度文件：`data/curated/starmap_ingest_progress.json`

## 每日命令

```bash
# 查看进度
python scripts/ingest_starmap_daily.py --status

# 执行下一批（默认 1 个 pending：抽取 → 增量入库）
python scripts/ingest_starmap_daily.py

# 只预览、不真正跑
python scripts/ingest_starmap_daily.py --dry-run

# 一天想多跑几个分卷
python scripts/ingest_starmap_daily.py --batch-size 2

# 指定某一天 / 某个文件
python scripts/ingest_starmap_daily.py --day 1
python scripts/ingest_starmap_daily.py --file "docs/熊猫资料/百度百科熊猫星图8.md"

# 重试失败项
python scripts/ingest_starmap_daily.py --retry-failed
```

## 等价手工步骤（单日）

```bash
python -m tools.panda_history_extractor --md-path "docs/熊猫资料/百度百科熊猫星图4.md" --category "熊猫资料" --max-concurrency 3
python -m tools.neo4j_graph_writer --result-json "data/wiki/<本次run>/<result>.json"
```
