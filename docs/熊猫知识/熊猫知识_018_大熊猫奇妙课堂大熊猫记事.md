# 大熊猫奇妙课堂 | 大熊猫记事

**大熊猫记事**

**古代对大熊猫的称谓**

古人对大熊猫的称谓很多，在秦代有一个叫上林苑的宫苑，苑中就有大熊猫的饲养记载。据汉代文学大师司马相如在《上林赋》中记载：“其兽则庸旄貘嫠。”明代李时珍所写医学巨著《本草纲目》和地理学家曹学佺所著《蜀中广记》,
分别从药物学和地理学方面,对古时历代记述熊猫的史实进行了总结。清代诗人王士祯所著《香祖笔记》,
记述在四川范山模水中,峨眉(峨眉县)、瓦屋山(洪雅县)及雅州(雅安市)产貔貅。足见大熊猫的古籍名一直延用到清代，与那时在产区的俗名“白熊”并存。

**西方世界和大熊猫**

**1、“大熊猫”名称的由来**

1825年，法国著名动物学家G·居维叶的儿子F·G·居维叶在喜马拉雅山发现了小熊猫，第一次出现了熊猫( Panda
)这个动物学的名称，拉丁学名为“ailurus fulgens”，意思是“一种火红色的或闪闪发亮的猫”（后来翻译成中文小熊猫）。

1869年，法国传教士A·戴维神父在四川宝兴发现了大熊猫,把它定名为黑白熊。1939年中国第一次在重庆北碚平民公园展出饲养大熊猫，展出的名字标牌上分别用中、英文字书写“猫熊”，由于当时中文的读写习惯是从右往左，因此游人都将“猫熊”读成了“熊猫”。

**2、西方世界对大熊猫的猎捕**

1929年，美国罗斯福总统的两个儿子,西奥多.罗斯福和克米特.罗斯福在四川冕宁冶勒同时开枪猎杀了1只成年雌体大熊猫保存于芝加哥自然历史博物馆。1934年，美国萨基和谢尔登到四川汶川,同时开枪猎杀了1只成年雌体大熊猫,保存于纽约自然博物馆。

现在在圣彼得堡、巴黎、伦敦、纽约、华盛顿等博物馆仍可以看到许多大熊猫标本，这些都是这段历史的见证。

**3、大熊猫国际交往的历史**

1941年，蒋介石夫人宋美龄以她个人名义送给美国人民一对熊猫(潘弟、潘达)以感谢他们对中国抗日战争的援助，定居于纽约布朗克斯动物园。1957年，前苏联最高苏维埃主席团主席伏罗希洛夫访华，我国政府首次以国礼赠送“平平"和“碛碛”两只大熊猫在莫斯科国家动物园展出。1972年，美国总统尼克松访华,我国以国礼赠送给美国人民一对熊猫“玲玲"和“兴兴”。

为了保护好“国宝”大熊猫这珍稀动物，自1988年，世界自然基金会(WWF)、国际自然保护联盟(IUCN)和美国动物园和水族馆协会发表了联合声明,呼吁禁止所有对大熊猫的租借行为。我国政府于20世纪80年代宣布停止赠送大熊猫。

**中国从五十年代至今**

**关于大熊猫的大事件**

**1、建立大熊猫生态观察站的历史**

1974年，由四川南充师范学院生物系(今四川西华师范大学生命科学学院)胡锦矗教授牵头，组建了一支约30人的大熊猫野外调查研究队伍一四川省珍稀动物资源调查队，开始了我国第一次野外大熊猫调查活动(同时也是世界上第一次野生大熊猫数量的全面普查)。

1978年，原南充师范学院(现西华师范大学)在卧龙保护区建立了"五一棚大熊猫生态观察站”,
对大熊猫进行生态观察。1983年，在青川唐家河自然保护区,成立了白熊坪大熊猫生态观察站与卧龙五一棚观察站作对比研究。1987年，四川师范学院(现西华师范大学)在凉山建立了马边大风顶大熊猫生态观察站。1993年，四川师范学院(现西华师范大学)在相岭山系冕宁县冶勒自然保护区建立了相岭冶勒大熊猫生态观察站。

**2、全国大熊猫数量调查**

1974~ 1977年，四川、陕西、甘肃三省开始对大熊猫等珍贵动物进行第一次调查。结果查明有大熊猫2400多只。1985 ~
1988年，在四川、陕西和甘肃三省开展了全国第二次大熊猫调查,经统计全国野生大熊猫共有1100只。1999 ~
2003年，全国第三次大熊猫调查,结果显示我国野生大熊猫有1596只。2015年2月28日，国家林草局举行新闻发布会，公布全国第四次大熊猫调查结果。调查结果显示，截至2013年年底，全国野生大熊猫种群数量达1864只，圈养大熊猫种群数量达到375只。根据最新数据显示，截止2020年年底，全国野生大熊猫种群数量达1860只，圈养大熊猫种群数量已超过600只。

**3、我国对大熊猫保护的相关举措**

1961年，世界自然基金会(WWF)成立，WWF不仅以大熊猫为该组织的会旗和会徽，而且积极参与和推动了中国大熊猫的保护事业。我国从1963年开始建立了卧龙、王朗、白河和喇叭河等大熊猫保护区。

1985年4月，在全国对散存于个人和单位的大熊猫皮张进行了全面的清理。1987年7月14
日，要求“依法严惩猎杀、倒卖、走私大熊猫皮张的犯罪分子”，倒卖、走私一张大熊猫皮，按规定可以处10年以上有期徒刑、无期徒刑或者死刑，并处没收财产。1992年启动了"中国保护大熊猫及其栖息地工程”。

2004年，国家林草局召开会议确定,坚持以就地保护为主,易地保护为辅。会议确定中国保护大熊猫研究中心、成都大熊猫繁殖研究基地、北京动物园和陕西珍稀动物抢救饲养中心等4个为大熊猫人工繁殖基地。2017年1月，大熊猫国家公园体制试点正式启动。大熊猫国家公园试点区规划范围跨四川、陕西和甘肃三省，总面积为27134平方公里，涉及3个省12个市(州)
30个县(市、区)，整合各类自然保护地80余个。
