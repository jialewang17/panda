# 大熊猫奇妙课堂 | 大熊猫的邻居们

**大熊猫的邻居们**

**大熊猫的近邻**

与大熊猫共同生活在同一片栖息地的动物朋友有金丝猴，小熊猫，牛羚，红腹锦鸡，黑熊等。它们有着共同的经历，曾经受过冰川的袭击和严峻考验，然而它们都有效地借助于我国西南高山深谷的有利地形幸存至今。它们通过长期共存，协调地共同生活于同一区域，但各自占有自己的生存空间，组成了一个较为稳定的动物群落。

**小熊猫**

小熊猫，又称红熊猫，主要分布在喜马拉雅山南麓和我国的西南山区，小熊猫全身红棕色，尾部有十二条红  暗
相间的环纹。虽然小熊猫和大熊猫亲缘关系较远，两种动物同属食肉动物，但却以食素为主，主食为竹子。为了握竹子，小熊猫和大熊猫的前肢都长着一根“  伪  拇指”。

**川金丝猴**

川金丝猴主要分布在四川、陕西、甘肃、湖北境内。生性机警、擅长攀爬跳跃。在猴群中，常由几个雄性猴放哨，如发现异常就会发出警报声，猴群听到后立即鸦雀无声；同时也给视觉差的大熊猫提供了警戒的情报。

**羚牛**

羚牛又叫扭角羚，主要分布在我国的西南山区和秦岭山脉，数量稀少，中国仅存数千头，是我国的一级保护动物。喜食许多灌丛植物的芽、叶、树皮以及各种青草，在冬季它们还吃大熊猫不吃已枯萎的竹叶。

**红腹锦鸡**

红腹锦鸡主要分布在中国甘肃和陕西南部的秦岭地区，全身羽毛颜色互相衬托，赤橙黄绿青蓝紫具全，光彩夺目，是驰名中外的观赏鸟类。性机警，胆怯怕人。

**大熊猫的植物朋友**

大熊猫的伴生植物有珙桐、宝兴杜鹃、蓉城竹、篌竹等。

**珙桐**

珙桐，是国家一级保护植物，在第四纪冰川时期，大部分地区的珙桐相继灭绝，只有在中国南方的一些地区幸存下来，成为了植物界今天的“活化石”，被誉为“中国的鸽子树”。

**宝兴杜鹃**

宝兴杜鹃通常依附并生活在树上，或者是生于岩石上，产四川、贵州、云南。杜鹃花产于高海拔地区，喜凉爽湿润的气候，恶酷热干燥。

**竹子**

竹子既是大熊猫的主要食物，也是它的伴生动物。

竹子分为以下几种：

1、蓉城竹又名龙竹、甜竹，产于浙江、四川。箨鞘背面暗绿色至淡绿色并微带紫色。

2、篌竹，产于陕西、河南及长江流域以南各地，基部密生褐色刺毛，向上变稀。

3、油竹子，产四川西部海拔800-1550m石灰岩陡坡或溪岸边。

4、短锥玉山竹（峨眉玉山竹、大箭竹），产于盆地西部海拔1800-3800m的亚高山阔叶林和暗针叶林。

5、冷箭竹（麦秧子），是大熊猫重要的主食竹种。1983年曾大面积开花枯死。产于四川盆地西部山区、云南东北部和贵州(梵净山) 。

6、华西箭竹，产于甘肃南部和四川西部。

**大熊猫的敌人**

尽管大熊猫与世无争，但在它的栖息领域里，还是有一些与它们为敌的动物，如金猫、豹、豺、黄喉貂等，这些掠食性动物通常只对大熊猫中的幼仔和病弱年老者具有一定的威胁，对成年的健康大熊猫来说，基本没有什么伤害。

**亚洲金猫**

亚洲金猫，分布于东南亚、中南半岛和中国，常袭击大熊猫幼仔。体毛呈黄色，背脊呈棕黑色。

**花豹**

豹一般指花豹，分布在亚洲、非洲的许多地区，袭击少年大熊猫及年老病弱个体。

**黄喉貂**

黄喉貂，俗名也叫青鼬、黄腰狸等，体形柔软而细长，呈圆筒状。善于攀缘树木陡岩，行动敏捷。

**豺**

豺，是我国一级保护野生动物，主要袭击少年大熊猫或病弱老年个体。豺既能抗寒，也能耐热，常以围攻的方式，几乎在同域分布的大小兽类它们都能对付。

这些伴生动植物与大熊猫生活在同一片栖息地，我们保护大熊猫，就像撑起了一把大伞，大熊猫承担着一个光荣的使命—伞护种。以大熊猫为“伞护种”，在保护野生大熊猫的同时，为其他珍稀动物提供了保护伞。大熊猫作为“伞护种”可以说为整个栖息地生物多样性的保护，做出了重大贡献。
