# 大熊猫奇妙课堂 | 大熊猫的行为特征

**大熊猫的行为特征**

**内八字走路**

大熊猫是用内八字行走的，这种动作有利于减少能量消耗，以适应竹子这种低能量的食物。除此之外，大熊猫内八字的行走方式还跟它的骨骼、体型有很大关系，大熊猫体型庞大，后腿短，前腿长，用内八字走路可以减少体重对骨骼的不利影响，使身体重心往前移，给后腿分担压力。

**大熊猫的** **睡眠**

大熊猫每天约有一半时间在进食，另一半时间则是在睡梦中度过。在野外，大熊猫每次进食过后会睡上 2-4
个小时，睡醒后再继续进食；在动物园里，除了饲养员每天给它们喂食的时间外，其余的时间大熊猫都会选择休息。虽然它们体型庞大，但四肢很灵活，能够摆出各种各样的姿势，平躺、侧躺、俯卧、伸展或蜷成一团都是它们喜好的睡觉姿势。

但是大熊猫并不像其他熊一样有着冬眠的习性，在严冬的时候，它们依旧会在雪地中寻找食物。

**爬树高手**

大熊猫爱爬树，而且擅长爬树。因为大熊猫没有固定的休息场所，为了避免在野外遇到危险，熊猫妈妈会在孩子小时候教它们如何爬树以保证自己的生存安全。当然，有时候大熊猫爬树只是为了沐浴阳光和玩耍，有时求偶及婚配行为也会在树上进行。

大熊猫的爪子非常锋利，可以嵌入树干，而树干表面凹凸不平，使大熊猫能够在爬树上行的过程中牢牢地抓住树干，控制自己的身体平衡，更快地爬上去。而且很多大熊猫爬树非常快，比在平路上走路快得多。我们偶尔也会看到大熊猫从树上掉下来或者是打滑的场面，但是大熊猫的皮毛可以起到缓冲作用，而脂肪也可以起到保护作用。

**气** **味标记**

大熊猫常年生活在树木茂密的高山上或薄雾弥漫的竹林里，同类是非常少见的，为此，大熊猫主要通过气味标记来实现同类间的交流。大熊猫有好几种做标记的方式，它们常用尿液或肛周腺体的分泌物来做标记，将分泌物涂在柱子、树桩、墙上、地上以及它们经常经过的地方，做标记时，大熊猫通常会晃动头部，嘴巴半张，做完标记以后，大熊猫会剥掉标记处附近的树皮或留下抓痕，以引起其他大熊猫的注意。这些气味标记能让大熊猫们互相回避或聚到一起，同时也是它们在竹林里保持和平相处的秘诀。

在非发情季节，它们一旦闻到陌生大熊猫的气味，便会主动走开；在发情季节，雌性大熊猫会留下气味标记，表示她已经做好交配的准备，并且希望有雄性大熊猫前来。在大熊猫找到彼此后，便会转为声音交流，大熊猫依靠它们丰富的“语言”来表达求偶、生气等多种情绪。

**大熊猫与水**

大熊猫生活在高山地区，周边只有小溪、小河，几乎不用游泳就能顺利通过，所以很少有人拍到大熊猫游泳的画面，但其实大熊猫也会游泳。

如果身上沾了水或者过河涉水之后，也会像其他动物一样把身上的水抖掉。在水深的地方，大熊猫也会有溺水的危险。

大熊猫会长途跋涉寻找清净的水源，在饮水过度时它们会腹胀如鼓，行似醉汉，走路蹒跚或躺在水边，这就是民间传说中大熊猫的“醉水”习性。
