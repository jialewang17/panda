# 大熊猫奇妙课堂 | 大熊猫的外形特征

**大熊猫的外形特征**

**大熊猫的体型及颜色**

大熊猫的体型很肥，头圆圆的、尾巴比较短。野生大熊猫的体重为 60-73 千克；人工饲养的大熊猫体重为 80-125 千克，最重的达 180
千克。人工饲养的大熊猫略重，一般雄性个体稍微大于雌性个体。大熊猫肩高 650-750 毫米，臀高 640-650 毫米；体长一般在 1200-1800
毫米之间。

大熊猫的体色为黑白两色，头部和身体毛色黑白相间分明，但黑非纯黑，白也不是纯白，而是黑中透褐，白中带黄。秦岭地区的大熊猫个体偏大，体毛粗糙，腹毛略呈棕色。岷山地区的大熊猫则个体较小，体毛也比前者细，腹毛棕色不明显。大熊猫黑白相间的外表，有利于隐蔽在密林的树上和积雪的地面，也是一种警戒色。

**大熊猫的皮毛**

大熊猫的皮毛厚而粗，由针毛和绒毛组成，内层髓质厚，外层富含油脂，有良好的防潮、御寒作用。

大熊猫被毛比较粗硬，且具有一定弹性，底层有绒毛。它的被毛具有良好的保温防潮作用，所以大熊猫可以在寒冷的雪地里正常生活。根据大熊猫个体的体况不同，存在不同时间的换毛现象。

**大熊猫的面部特征**

大熊猫天生视力差，有大大的黑眼圈，黑眼圈其实和人戴墨镜，是同一个道理，黑眼圈能减弱射入眼睛的光线，同时吸收能对眼睛造成伤害的紫外线。夏天，一般在树顶上过夜，早上醒来，树顶光照强，地面上光线弱，就像我们人站在太阳下、看光线暗的地方看不清楚、需要戴上墨镜才能看清是一样的。大熊猫借助黑眼圈阻止强光照射，避免刺激眼睛，下树活动前可以看清地面情况，确认安全才下树。冬天也是，白雪反射太阳光会刺激眼睛，有黑眼圈可以遮挡光线，避免眼睛受刺激。

为了能够更好的咀嚼竹子，大熊猫的牙齿随着时间发生了很大的变化，现代的大熊猫臼齿宽大，咀嚼面上长了许多釉质凸起和棱脊，虽然仍保留了食肉祖先的犬齿，但因使用较少而逐步钝化。

**大熊猫“六指”的秘密**

大熊猫分属食肉目，是因为它们拥有典型的食肉目动物的消化系统。当它们以食肉和杂食为生的时候，它们的确拥有非常明显的五个手指，但在之后的演化进程中，在大熊猫的前掌上慢慢多出一个类似“手指”的东西来，肉眼看着就像是大熊猫有六个手指。其实，大熊猫实际上的手指数量为五个，这个多出的“第六个手指”并非真正意义上的手指，而是由腕部籽骨特化而来，成了俗话说的“伪拇指”，主要起握住竹子的作用。

那么这个腕部籽骨又是什么呢？说是“骨”，其实这是一个没有骨头的肉垫，这个肉垫是长不出指甲的，不过却有着大拇指的灵活，它可以和熊猫前掌五个手指实现对握。这种对握的本事在动物身上并不常见。动物进化的原因是生存与生活决定的，大熊猫多出来的“第六指”是为了更灵活更方便地获取并握住它的食物——竹子。

**大熊猫的尾巴**

大熊猫的尾巴是白色的。

大熊猫的尾巴很短，肛周区有一块无毛区域，该区域的腺体丰富，尾巴的其余部分毛比较蓬松，毛茸茸的。尾巴通常紧贴着身体，成为腺区、肛门和外阴的保护盖。当尾腺、肛周腺和外阴有分泌物排出时，大熊猫可以把尾巴当作刷子，四处标记信息。
