# 大熊猫奇妙课堂 | 生命的传承

**大熊猫繁育科普知识A**

**发情和受孕**

雌性大熊猫每年发情一次，通常在每年的3-5月，每次只有的2-5天。圈养条件下雌性大熊猫4岁左右，雄性大熊猫6岁左右进入性成熟，野生大熊猫性成熟稍晚。

成年雌雄大熊猫相互间主要通过气味嗅觉（通过留下气味标记和嗅闻标记）的通讯方式逐渐聚集在一个地方并相互了解、相互吸引，到发情高潮时相互间通过连续不断的咩叫和鸟叫声以及待配姿势等听觉、视觉通讯方式表达爱意并达成配对交配。

大熊猫是属于多雄争配制，自然环境中，公兽为争夺配偶相斗十分激烈，获胜者才能取得交配权。在大熊猫交配场地有时有多达2-5只雄性大熊猫通过打斗竞争并先后都与同一雌性大熊猫成功交配的情况，也有仅一只雄性与一只雌性大熊猫交配的情况。在圈养条件下，则根据大熊猫繁育系数，安排它们配对。

**怀孕**

大熊猫妊娠期为83-324天，幼仔出生的巢穴通常是一个隐蔽的树洞，或天然的岩洞，里面有大熊猫妈妈精心铺垫的树枝和干草。

**生产**

大熊猫繁育最奇特的一点是它的新生儿在出生时发育相当的不成熟，初生幼仔体重很轻，约150克，仅是母亲体重的千分之一。

刚出生的大熊猫皮肤是粉红色的，带有稀疏的白毛。在它刚出生的几周里，大熊猫妈妈会一直将孩子抱在怀里，温暖它、保护它，几乎寸步不离，移动的时候就把它衔在嘴里。

在野外，如果出生的是双胞胎（圈养下，大熊猫产双胞胎比例近50%），大熊猫妈妈通常会忽视或拒绝较弱的一个，这能保证至少一只成活。同时，由于大熊猫生殖能力和育幼行为两方面的高度特化，使大熊猫的种群增长十分缓慢。在圈养情况下，会进行人工饲养，并采用换仔技术，尽量使所有的大熊猫幼仔都能成活。

**育幼**

照顾孩子对于雌性大熊猫来说是一项非常艰巨的任务，这段时间在大熊猫的一生中是非常重要的。大熊猫幼仔能从它们的妈妈那里学到很多东西：比如怎样寻找食物和水源，怎样躲避天敌，抵御疾病。

大熊猫育幼期间，母乳是大熊猫幼仔的最佳营养来源，尤其是初乳（大熊猫产后前三天的奶称为初乳，初乳呈淡绿色，有点像竹叶的汁液。三天后的奶称为常乳。），它含有大量的免疫因子，促进大熊猫幼仔的生长发育。

幼仔的叫声是母仔间联系非常重要的通讯工具，幼仔想吃奶、想排便、受冷或过热或其他原因的不适，幼仔都通过不同叫声提醒母兽满足其不同需要。

**成长**

刚出生：初生大熊猫幼仔体重仅是它母亲体重的千分之一，平均体重仅120克左右，最轻的为51克，最重的为225克。粉色的皮肤上长着白毛，眼睛和耳朵还没有发育完全，免疫系统的也还未发育完善。

一到两周：肩带、四肢和耳朵渐渐变黑。

一个月：长出黑白相间的毛，变得更像妈妈了。体重1~2公斤，还不能行走。

六到八周：可以睁眼。

三个月：可以慢慢的爬动了。

半岁：可以自由行走，开始学吃竹子。

一岁：开始长出恒牙。

一岁半：离开母亲，独立生活。

亚成年：一岁半到性成熟前为亚成年阶段，相当于人类的青少年时期。这一阶段大熊猫的食物从营养丰富的奶为主逐渐过渡到以高纤维、低营养的竹类为主。生理和心理上也逐渐成熟，即将开始繁育后代。大熊猫在1~3岁期间是最为活跃的时期，每天除了采食外，大部分时间都在玩耍、探索和爬树。

成年：体长约160~180厘米，体重约80~150公斤。
