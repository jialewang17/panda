# 大熊猫奇妙课堂 | 圈养大熊猫的成长阶段

**圈养大熊猫的成长阶段**

被圈养的大熊猫从小就在饲养员和基地的关心爱护下成长，一直到老掉牙、走不动路。在照顾不同阶段的大熊猫时，需要注意的地方也不同。

**幼年大熊猫**

大熊猫初生幼仔的重量一般在150克左右，就是一胎两仔也不过300克左右，是非常脆弱的，需要小心呵护。

大熊猫幼仔生长速度迅猛，在饲养上需要特别注意。勤喂多餐，每日饲喂4-5次。幼仔断乳前，其生长发育所需的营养物质主要是通过母乳获得，母兽饲养的优劣对幼仔的生长发育有直接影响。一般幼仔六月龄时断乳，如果幼仔生长发育不理想，可适当推迟断乳时间。

在断乳之后，人工奶是人工饲喂大熊猫幼仔的主要食物，国内外已进行了长期的探索和试验。根据月龄和体重情况，每日可饲喂3-4次人工奶，中间可添加米粥、鸡蛋、糖、盐、钙片、多种维生素和微量元素等。特别需要注意鱼肝油与维生素E的补充，维生素E对大熊猫的性腺发育有促进作用。

据目前所知，人工奶大部分是多种奶粉和动物母奶配制而成，其中包括牛、羊、人的初奶及常奶。人工奶的配方虽有所差异，但都是经过准确的营养配比。

**亚成年大熊猫**

亚成年大熊猫处于幼年向成年过渡的阶段，从幼嫩趋向成熟。这个阶段发病率达到50%，病死率约37.5%。需要非常细心的观察照料，防止发生意外。

这一阶段要尽量做到食物营养均衡，竹子新鲜，饲料要尽量满足总能量与粗蛋白的需求，这些是亚成年大熊猫比较需要的营养成分。

另外，还要求环境能满足它的运动量、环境富化、活动多样化，尽量使其沐浴较多的阳光。在进入亚成年阶段之后，大熊猫就需要拥有自己的单独圈舍了。

**成年大熊猫**

饲养成年大熊猫相对来说容易一些，只要每天提供足量的食物，有一定的活动空间及运动量，能在一个清洁、安静的环境中得到充分的休息，成年大熊猫一般都很少患病。但成年大熊猫在不同的生理时期，还是要有所区别对待。

种公兽是用于自然交配和人工采精的，在饲养上除了需要提供充足的新鲜竹子外，还要给予较多的蛋白质，重点添加维生素E、维生素A,以及微量元素锰、锌、硒等。

发情期内的大熊猫一般食欲都有程度不同的减退，对精料不太喜食，偏食竹类饲养，尤其是新鲜竹叶。在发情期内应供给更多的青绿饲料，精料的供给量可适当减少。每只雌性大熊猫发情期内的食量及嗜好是不同的，要认真观察、记录、研究，以便于大熊猫进行更科学的饲养。

为了保证胚胎的正常发育，必须根据大熊猫不同妊娠期的营养需要给以满足。健康雌性大熊猫在妊娠期时，其食欲不会有多大变化，可按正常数量喂给新鲜的竹叶、竹杆和竹笋。在妊娠中后期，为满足胚胎发育有对蛋白质的需要，应在窝窝头中添加一些质量高的营养物质，如鸡蛋、酵母、鱼肝油及多种维生素等，尤其应注意补充一定量的骨粉或钙片。临产前，随着雌性大熊猫活动量的减少，其食欲有所下降，精料可减少1/4，但竹叶、竹杆和竹笋还应任其自由采食。

**老年大熊猫**

老年大熊猫和其他老年动物样，整个机体都处于衰退期，身体各系统和器官功能逐渐衰弱，活动量减少，对圈舍的实际利用面积不大，但需要一个环境丰富、幽静的栖居条件。

老年大熊猫对竹子的咀嚼和消化能力降低，食物来源受阻，势必影响其营养乃至生命。应根据个体的身体状况和对饲料的喜好特点，遵照“少量多餐”的原则，制定个性化的饲料与饲喂方法，提供适量的竹笋，确保每日粗饲料的摄入量，降低排粘频率。对于牙齿磨损严重或脱落的老年大熊猫，需将竹叶剪成1-2cm的碎片，再与每餐所需投食的精料、果蔬类等混匀，放于盆中投喂，方便其采食。对于消化能力降低者，除了提供碎竹叶外，还用流质配合饲料代替窝窝头，并添加安素等易吸收的营养素，确保每日摄入量足够和营养的均衡。

随着年龄的增长，自身的免疫功能退化，各种器官机能也随之退化，发生疾病的可能性大大增加，各种生理性病变都会让老年大熊猫发病。因此，需要采取积极的预防措施，以延缓或防止疾病的发生。做好兽舍环境卫生、消毒、补克维生素和微量元素、定期驱虫等都是最基础的。
