# 大熊猫奇妙课堂 | 海归大熊猫

**海归大熊猫**

中国大熊猫保护研究中心为整合国内外科研技术资源，促进大熊猫保护事业发展奠定了基础，也为开展大熊猫科普教育和文化传播搭建了更大的平台，已经成为全世界开展大熊猫科研合作和公众教育所需大熊猫个体的最主要输出基地和交流平台。

**中国大熊猫保护研究中心**

**海归大熊猫**

1、大熊猫“福龙”“福虎”“福豹”“福凤”“福伴”

2003年3月3日，在中国保护研究中心专家的护送下，大熊猫“龙徽”“阳阳”抵达奥地利美泉宫动物园。中奥双方开展大熊猫科研合作交流十五年来，双方紧密围绕大熊猫繁殖、疾病防控、饲养管理、科普教育等方面开展交流合作，先后成功繁殖“福龙”“福虎”“福豹”“福凤”“福伴”五只大熊猫。

大熊猫“福龙”2007年8月23日在奥地利美泉宫动物园出生，2009年11月回到中国大熊猫保护研究中心。

（大熊猫“福龙”）

大熊猫“福虎”于２０１０年８月23日出生在维也纳美泉宫动物园，大熊猫“福虎”已于２００12年１１月回到中国大熊猫保护研究中心。

（大熊猫“福虎”）

大熊猫“福豹”于2013年8月14日出生于奥地利美泉宫动物园，2015年11月，福豹从奥地利回到中国大熊猫保护研究中心生活。

（大熊猫“福豹”）

2016年8月7日大熊猫龙凤胎“福凤”“福伴”出生于奥地利美泉宫动物园，这是迄今为止，世界范围内，圈养大熊猫全母兽抚育双胞胎成活的第一例。大熊猫“福凤”和“福伴”于2018年12月4日回到中国大熊猫保护研究中心，成为首对海归大熊猫双胞胎。

（“福凤”）

（“福伴”）

（首对海归大熊猫双胞胎）

2、大熊猫“华美”“美生”“苏琳”“珍珍”“云子”“小礼物”

1996年9月10日雌性大熊猫“白云”和雄性大熊猫“石石”(2003年回国)一起前往美国圣地亚哥动物园生活，1999年8月21日，大熊猫“白云”生下和大熊猫“石石”的女儿大熊猫“华美”，大熊猫“华美”于2004年2月13日回到中国大熊猫保护研究中心。

（大熊猫“华美”）

2003年大熊猫“白云”与来到美国圣地亚哥动物园生活的大熊猫“高高”坠入爱河，大熊猫“高高”于2018年11月1日回到了中国大熊猫保护研究中心。在中美双方共同努力下,大熊猫
“高高”和“白云”共繁育了五只后代,分别是大熊猫“美生”、“苏琳”、“珍珍”、“云子”、“小礼物”。

2003年8月19日，大熊猫“美生”出生在美国圣地亚哥动物园，于2007年11月7日回到中国大熊猫保护研究中心。

（大熊猫“美生”）

2005年8月2日，大熊猫“苏琳”出生于美国圣地亚哥动物园,于2010年9月26日回到中国大熊猫保护研究中心。

（大熊猫“苏琳”）

2007年8月3日，大熊猫“珍珍”出生于美国圣地亚哥动物园,于2010年9月26日回到中国大熊猫保护研究中心。

（大熊猫“珍珍”）

2009年8月5日，大熊猫“云子”出生于美国圣地亚哥动物园,于2014年1月11日回到中国大熊猫保护研究中心。

（大熊猫“云子”）

2012年7月29日，大熊猫“小礼物”出生于美国圣地亚哥动物园，2019年5月16日27岁的“白云”和6岁的“小礼物”回到四川“老家”。这是大熊猫“白云”时隔23年后首次回到家乡，也是大熊猫“小礼物”跟随妈妈第一次踏上家乡的土地。

（大熊猫“白云”）

（大熊猫“小礼物”）

3、美国华盛顿动物园：泰山、宝宝、贝贝、小奇迹

2001年1月10日来自中国大熊猫保护研究中心的熊猫夫妇“添添”“美香”前往美国华盛顿国家动物园，开展科研合作。期间，在中美双方共同努力下，两只大熊猫产下了爱的结晶：“泰山”、“宝宝”、“贝贝”、“小奇迹”。

2005年7月9日，大熊猫“泰山”出生于美国华盛顿国家动物园，于2010年2月5日回到中国大熊猫保护研究中心。

（大熊猫“泰山”）

2013年8月23日，大熊猫“宝宝”出生于美国华盛顿国家动物园，于2017年2月22日回到中国大熊猫保护研究中心。

（大熊猫“宝宝”）

2015年8月22日，大熊猫“贝贝”出生于美国华盛顿国家动物园，于2019年11月21日回到中欧大熊猫保护研究中心。

（大熊猫“贝贝”）

2020年8月21日，大熊猫“小奇迹”出生于美国华盛顿国家动物园。

（大熊猫“小奇迹”）

**关于大熊猫的运输**

在使用飞机运输大熊猫时，需要确认有氧、调温的货仓。当然，在运输之前还有一些手续需要办理，如大熊猫等一级保护动物的转移和运输需要国家林草局的批文，再就是检疫手续文件。另外，运输前要对大熊猫进行一些必要的噪音、搬运的适应性训练，避免临时操作引起大熊猫紧张与恐慌。还要事前进行大熊猫的人笼训练，利用食物引诱大熊猫经常进出运输笼，去机场前就容易将大熊猫引人笼中。大熊猫运输笼周边最好在通风通气的前提下安装挡板，以遮蔽大熊猫视线，避免周边噪声和景物惊吓大熊猫。

**海归大熊猫现状**

作为全世界最重要的大熊猫国际国内合作交流平台，中国大熊猫研究中心先后与14个国家15家动物园建立了大熊猫科研合作关系，有着全世界最大的大熊猫海归种群。海归大熊猫“林冰”“宝宝”“泰山”等都有了后代，续写中国与相关国家人文交流以及大熊猫情谊佳话。
