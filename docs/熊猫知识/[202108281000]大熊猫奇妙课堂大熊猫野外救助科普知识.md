# 大熊猫奇妙课堂 | 大熊猫野外救助科普知识

**大熊猫野外救助科普知识**

中国是一个发展中国家，人口众多，自然资源相对贫乏，在人类漫长的经济、社会发展进程中，自然景观破坏的程度较重，经济发展与自然保护之间的矛盾尤为突出。栖息地破坏、碎片化、岛屿化成为中国一些兽类数量减少、分布区面积缩小、濒临灭绝的最重要原因。

中国大熊猫保护研究中心利用先进的技术和设备积极开展野外大熊猫线的工作先后成功抢救100余只衰老、病饿、受伤的野生大熊猫，其中有部分熊猫在得到成功救治后被，放归到野外，这样的做法大大降低了野生大熊猫的非正常死亡率。同时还有一些无法再适应野外环境的老年、残疾大熊猫在中国保护大熊猫研究中心也得到了相对妥善的安置，其中有部分还参与了大熊猫的繁殖，为保持圈养大熊猫种群的遗传多样性作出了贡献。

**野外救护需要具备的条件**

在野外救护野外患病大熊猫是一项非常艰苦的工作，不仅需要经验丰富的兽医，而且还需要精心准备有效、实用的医疗设备。在大多数情况下，需要救护的患病大熊猫大多都出现在山区地带，因此，除了必须的医疗设备外，还需要配备能够应对复杂环境状况的交通工具、抢救笼、固定绳索、麻醉枪、氧气瓶、麻醉剂等急救设备、材料和药品。为大熊猫抢救治疗的工具和人所需要的工具是一样，比如：听诊器、手术刀、手术剪、血管钳等。

**野外救助中麻醉的使用**

麻醉是利用化学药物保定动物的一种常用手段，在抢救、治疗、转移等很多时候都需要用到麻醉剂。在给大熊猫麻醉前，尽量禁食24小时、禁水12小时。如果大熊猫因为治疗需要较长时间，一般就会采取基础麻醉后通过呼吸道输送的气体麻醉。

在为大熊猫治疗时，为了减少麻醉剂对大熊猫身体产生负面影响，兽医只有在特殊的情况下才会使用麻醉剂(如输液治疗、外科手术等)。通常，兽医采用肌肉注射麻醉的方式对大熊猫来进行麻醉；如果需要长时间做手术，则会使用吸入麻醉机做维持和补充麻醉。在平时，饲养员也会科学的训练大熊猫在非麻醉情况下接受日常治疗和常规检查。大熊猫常用麻醉剂和人类是差不多，只是使用剂量不同。

**大熊猫体外伤的护理**

大熊猫的体外伤多由熊猫相互之间打斗所导致，无论出现哪种情况，首先应该查明致伤原因，迅速对受伤表面进行消毒处理，同时消除伤口中的异物，剪除创伤周边被毛。如有流血，要先进行血管结扎，并探查有无肌肉、筋腱、骨骼损伤。经严格消毒后，及时清理创伤部位，缝合肌肉和皮肤，涂抹抗生素或肌注抗生素，然后进入常规护理和治疗程序。

**大熊猫的血液采集和输血治疗**

大熊猫的血液采集，需要经验丰富、基本功扎实的兽医来完成。因为大熊猫的毛皮比较厚实，与人相比，探摸静脉是非常困难的，而下颈部被毛相对稀疏、皮肤柔软、血管较粗，血管会膨胀，用手指可以探摸到静脉血管，所以采血部位一般就会选择下颈部和前肢内侧。采血前，要剪去采血部位的被毛，先用碘酊消毒，再用75%的酒精消毒，做好一切准备工作后，最后才下针。

在野生大熊猫的抢救工作中，如果碰到救治失血、休克、败血症、肾衰竭、严重贫血等病危大熊猫时，输血治疗就显得尤为重要，输血对受血机体能起到补充循环血容量、维持正常血液循环的作用，还能促进机体各器官系统机能的改善，所以输血是临床治疗常用的重要方法之一。但野生动物的输血研究，客观上由于病例少，血源困难，有关配血和输血方面的基础研究还不够，所以仅处于试验研究的初级阶段。
