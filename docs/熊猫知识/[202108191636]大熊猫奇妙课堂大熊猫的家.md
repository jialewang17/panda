# 大熊猫奇妙课堂 | 大熊猫的家

**大熊猫的家**

**大熊猫的自然栖息地**

野生大熊猫多栖息于高山深谷，为东南季风的迎风面，气候温凉潮湿，其湿度常在80%以上，故它们是一种喜湿性动物。这些地方土质肥厚，森林茂盛，箭竹生长良好，构成为一个气温相对较为稳定、隐蔽条件良好、食物资源和水源都很丰富的优良食物基地。

大熊猫的自然栖息地现仅存于我国的四川、甘肃和陕西3省的六大山系：从北到南依次为秦岭、岷山、邛崃山、大相岭、小相岭和凉山。大熊猫分布于青藏高原东缘六大山系的高山峡谷，大熊猫一般生活在海拔1500-3500米的茂密竹林里，这里空气稀薄，云雾缭绕，气温常年低于20℃，凉爽湿润。

大熊猫栖息地的必要条件主要有五个方面：栖息地面积足够大，竹子食物充足，水源距离适中，繁殖场所存在，人为干扰少或无。关键因素是竹子、水和产仔巢穴。

**大熊猫栖息地的分布与变化**

在人类史前时期，大熊猫在我国的山西、河南、湖北、湖南、贵州和云南等地区的低山区尚有分布，但自进入铁器时代以来，随着人口增加及生产和生活区域的扩大，大熊猫进一步向中国西部山区退缩，在唐宋元时期，大熊猫向西退缩的速度较为缓慢。进入明清时期，随着人口的暴涨以及土豆、玉米等适应山区环境的外来农作物的大量种植，大熊猫退宿速度加快，至清末时山西、河南、云南、湖北、贵州等省分布的大熊猫已基本绝迹。目前，野生大熊猫仅生存在四川、陕西、甘肃三省，包括秦岭、岷山、邛崃山、大相岭、小相岭及凉山等六大山系的原始森林中。

**大熊猫种群的变化**

通过重建从始熊猫到大熊猫现生种的物种进化历程，大熊猫家族表现出了两次显著的扩张和收缩。大熊猫种群的两次扩张和收缩变化与古气候动荡变化密切相关，表现为冰期气候寒冷导致种群缩小，间冰期气候回暖为大熊猫种群扩张提供了有利条件，近3000年以来人类活动则是导致大熊猫近期变化的主要因素。据野外调查显示，截至目前，我国大熊猫野生种群增至1864只。

**大熊猫栖息地面临的威胁**

大熊猫野外种群数量达到1800多只，受威胁程度等级由濒危降为易危。大熊猫种群数量减少的根本原因，是缘于人类社会生产活动的加剧。

具体而言为以下几点：一是森林砍伐，大熊猫栖息地每年的采伐面积达到至少1万公顷，其栖息地快速在消失。二是人类修建的道路、桥梁、开垦的农田、种植经济作物，严重干扰了大熊猫的正常生活，造成栖息地破坏；三是过度采集、非法猎捕，为了追求经济发展，刺激且加剧了盗猎和非法采集野生药材的活动。

**大熊猫栖息地植被**

中国大熊猫栖息地主要位于中国四川省境内，分布于川西高原东部的的岷山、邛崃山、大相岭、小相岭、凉山以及秦岭等6块狭长地带，横跨川、陕、甘三省境内，整个栖息地面积超过2万平方公里。川西山地受到海拔高度影响气候带呈现垂直分布，形成复杂多样的小气候群，川西山地植物区系起源古老，主要分布六种植被类型，植被种类约5000-6000种，具有较多的特有种属和孑遗植物，如鸽子树、水杉等，杜鹃花科、竹科和兰科呈现丰富的多样性。
