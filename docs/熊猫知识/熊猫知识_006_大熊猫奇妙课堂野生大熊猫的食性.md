# 大熊猫奇妙课堂 | 野生大熊猫的食性

**野生大熊猫的食性**

**野生大熊猫的食物构成**

野生大熊猫的食谱组成
99%以上都是竹子，偶尔也会采食其他食物，例如山区农作物（玉米、南瓜、小麦等）、野生植物的果实（猕猴桃、野樱桃等）以及草本植物（野当归、蕺菜、青茅等）。除此之外，野生大熊猫也会捡食一些被其他肉食动物猎杀或严寒天气冻死的动物尸体。当然，极少的野生大熊猫会在冬季进入城区，来到村民家中采食庄稼和家畜。

**主食竹类**

野生大熊猫可食用竹类有12属60多种，如：蓉城竹、篌竹、冷箭竹、油竹子、拐棍竹、华西箭竹、少花箭竹、、巴山木竹、短锥玉山竹等。这些竹子主要生长在亚高山暗针叶林、山地暗针叶林、山地针阔叶混交及山地常绿阔叶林的林冠下，分布海拔从700m-3500m不等。

不同山系的野生大熊猫，喜欢的竹子种类也有差异。岷山山系的喜欢巴山木竹、刺竹等；邛崃山山系的主要采食冷箭竹、华西箭竹等；大小凉山山系的主要食谱只有5种，如玉山竹、丰实箭竹等；秦岭山系的则喜欢吃华桔竹、巴山木竹等。

**野生大熊猫的食量**

大熊猫的食量非常大，每天要进食竹子12-18公斤或10-14公斤竹叶或约40公斤的竹笋。因为大熊猫还保留着肉食动物的消化道，它对竹子干物质的消化率只有约为17%，其余的都会很快排出体外。而且大熊猫在休息时间都需要大约60%的热量维持身体的基本功能，所以大熊猫要通过大量吃竹子来获取能量。

**大熊猫的进食方式**

大熊猫每天需要花费近一半的时间来进食，它们并不在乎在什么地方吃，也不在乎用什么姿势吃，它们只是不停的剥竹竿、吃竹叶，端坐、平躺、侧卧都是大熊猫常见的吃相。

大多数野生大熊猫都会在溪涧流水附近寻找住处，以便饮水，它们每天至少饮水一次，因而在那些食物丰富却缺乏水资源的地方，难以找到大熊猫的身影。

大熊猫取水总是求近舍远，它们到了溪边，会以舔吸的方式饮水，若溪水结薄冰或被沙石填没，则用前掌将冰击碎或用爪子挖一个浅坑舔饮。

**野生大熊猫的捕鼠行为**

在野生大熊猫的栖息地存在着一种害鼠，名叫竹鼠，俗称“竹溜子”，专吃箭竹的地下根，使箭竹枯死。竹鼠的肉鲜嫩可口、营养丰富，正像当地的俗话：“天上的斑鸠，地上的竹溜”。它是大熊猫食物的竞争者，有互相争取食物空间的行为或捕杀和嬉戏行为。

大熊猫对付竹鼠有一套巧妙的办法，一旦闻到竹鼠的气味或发现其踪迹，大熊猫很快就能找到它的洞穴，然后用嘴向洞里喷气，并用前爪使劲拍打，迫使竹鼠慌忙出逃，大熊猫再趁机一跃而上，用前爪按住竹鼠，抓到之后，撕去鼠皮，尽食其肉。如果竹鼠不出洞，大熊猫就会挖洞抄家，直到最终将竹鼠捕获。
