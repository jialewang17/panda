# 大熊猫奇妙课堂 | 大熊猫的保护

**大熊猫的保护**

作为世界自然基金会（WWF）的标志，大熊猫深受全世界人民的喜爱。由于它的濒危程度，大熊猫得到了史无前例的特别保护。

**保护大熊猫的作用**

人类能够投入在动物保护上的资源是有限的，不可能把每一种需要保护的动物都保护到。所以最好的办法就是在保护一种动物的同时也保护到了其他的动物。这样被选出来的代表物种就是伞护种。

大熊猫就是一个典型的伞护种，野生大熊猫偏好栖居在没有人为干扰的成熟原始森林，对大熊猫保护的投入也广泛惠及了跟它同域分布的其他野生动植物。

**大熊猫的就地保护与迁地保护**

在保护自然界野生动植物方面，分为就地保护与迁地保护两种形式。

就地保护是指原地就需要保护的物种和将整个生态系统完整地保护起来，比如建立保护区的方式。  使亟待保护的物种和生物多样性尽量不  受
人类的干扰与破坏，从而使  保护物种得到持续、稳定、良好的延续。  大熊猫的就地保护也是如此。

大熊猫的迁地保护是就地保护的重要补充。因为大熊猫的栖息地遭到严重破坏，其种群生存受到威胁，在野外很难维持种群可持续发展的情况下，把需要保护的大熊猫转移到另外一个地方或环境中，这种措施就叫做大熊猫的移地保护。这里所说的“移地”，往往是人工环境，如动物园、实验场或驯化养殖场。在移地保护适宜的环境中，可以充分观察和研究大熊猫在野外不能获得的生理、生化及行为基本数据，同时利用人类社会先进的科学技术手段辅助大熊猫正常地生长发育，并且达到高效率的繁衍，使移地保护的人工种群数量得到迅速增加。

世界自然保护联盟
(IUCN)主张，当一个动物种群在整个自然环境中的总数量下降到1000只(头)左右时，就有必要将一部分珍稀动物转移到适宜、安全、有保障的人工环境中。通过人工饲养、繁育，使该动物的人工种群达到自我繁衍与维系，在达到一定数量后，再进行野化放归，去有计划地、科学地重建和复壮野外种群。
另外，在大熊猫的迁地保护过程中，可以方便地对大熊猫进行多学科的科学研究，了解其行为、习性生理、疾病等方面的数据。还可以开展丰富多彩的公众教育活动，提高人们保护大熊猫及其生态环境的意识。

**我国保护大熊猫的措施**

**1.大熊猫自然保护区**

中华人民共和国成立后，我国政府非常重视大熊猫等野生动物的保护，并为此颁布了《稀有动物保护办法》。1988年颁布了《中华人民共和国野生动物保护法》，2016年又对《中华人民共和国野生动物保护法》进行了修订。

我国自1963开始建立以保护大熊猫为主的自然保护区，第一批有卧龙自然保护区、王朗自然保护区、喇叭河自然保护区、白水河自然保护区，覆盖面积约900平方千米。

1970年后，根据大熊猫分布，又建立了8个国家级自然保护区:即四川蜂桶寨国家级自然保护区、陕西佛坪国家级自然保护区、甘肃白水江国家级自然保护区、四川马边大风顶国家级自然保护区、四川唐家河国家级自然保护区、四川小寨子沟国家级自然保护区、四川美姑大风顶国家级自然保护区、四川九寨沟国家级自然保护区。

20世纪80年代又新增加了23处以保护大熊猫为主的自然保护区。截至1989年底，我国在四川省、陕西省和甘肃省共建立了13个以保护大熊猫及其栖息地为主的自然保护区。

**2.大熊猫野生生态观察站**

“五一棚”观察站位于四川省卧龙国家级自然保护区的一个山坡上，
这是世界上第一个大熊猫野外生态观察站。国内外学者基本都是从这里开始了解大熊猫、探索与研究大熊猫的。另外，还有陕西省的佛坪三官庙观察站、洋县大熊猫观察站，四川省的唐家河白熊坪观察站、马边大风顶观察站、冕宁冶勒观察站等。

**3.大熊猫人工繁育**

我国人工圈养大熊猫在繁殖方面一直面临着 “发情难、配种受孕难、育幼成活难”
三大难题。经以四川卧龙“中国大熊保护猫研究中心”为首的多家单位科研人员共同努力，20世纪90年代中后期攻克圈养大熊猫繁育的“三难”，从1999年以来，我国圈养大熊猫种群发展步入高速发展时期。截至2007年底，全国圈养大熊猫数量达到239只，其中人工条件下繁育的个体超过70%，彻底结束了依靠野外大熊猫个体维持圈养种群的局面，基本步入自我维持初级阶段，并具备了向野外补充大熊猫个体的能力。
