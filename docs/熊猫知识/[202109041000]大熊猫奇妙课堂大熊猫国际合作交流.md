# 大熊猫奇妙课堂 | 大熊猫国际合作交流

**大熊猫国际合作交流**

**和平与友谊的使者**

大熊猫以其独特的魅力，深受着世界人民的喜爱。所到之处，一次次掀起了“大熊猫热”，产生了广泛的影响。大熊猫在为世界各地民众带去欢乐的同时，也成为促进世界和平与友谊的使者。

30年来，大熊猫在促进中国人民与世界人民友谊和文化交流方面，扮演着重要的角色，经常出现在各类国际交流重大活动中，向全世界展示其风采，展示中国在以大熊猫为代表的野生动物和生态环境保护领域取得的辉煌成绩，传播生态文明理念。

**友好使者的历史**

在我国，大熊猫作为对外交往礼物可谓历史悠久，自唐朝武则天开始，大熊猫就已经成了搭建国与国之间友好交往的桥梁。

1941年，宋美龄曾将一对大熊猫“潘达”“潘弟”送给美国。

中华人民共和国成立后，自1957-1980年，我国政府陆续将25只大熊猫作为国礼赠送给了9个国家。

1972年2月，美国总统尼克松访向中国，中美外交从此翻开了新的一页，在此之际，为了满足美国政府希望中国馈赠大熊猫的请求，中国政府决定赠送给美国人民一份国礼，即大熊猫“玲玲”“兴兴”。当时，“玲玲”“兴兴”抵达华盛顿时，美国各界人士八千余人冒雨迎接，各大媒体纷纷报道，盛况空前。这一年，被美国定为“大熊猫年”。

截至目前，中国大熊猫保护研究中心先后与美国圣地亚哥动物园、华盛顿动物园，日本神户王子动物园，东京上野动物园，泰国清迈动物园，奥地利美泉宫动物园，澳大利亚阿德菜德动物园，英国爱丁堡动物园，新加坡河川生态园，马来西亚布城湿地公园和比利时天堂动物园等14个国家的15个动物园建立了良好的合作关系。

**WWF图标背后的故事**

WWF的大熊猫徽标灵感来自于Chi-Chi。Chi-Chi是一只于1961年移居伦敦动物园的大熊猫。而WWF正筹建于1961年。

WWF当时特别需要一种能够跨越人类语言和文化障碍的标志，这种标志一定要容易被识别并且可以让人轻易产生强烈的印象。大熊猫有着毛茸的圆滚可爱体形和吸引人的充满魅力的黑色大眼圈。WWF的筹建者们一致认为它的形象极适于作为组织的标志。

第一个草图是由英国环境主义者和艺术家Gerald Watterson打的底稿。WWF的筹建者之一，Peter
Scott爵士，在这个基础之上，绘制了第一个正式的WWF徽标。

他在当时表示：“我们选择它，是因为它是美丽可爱的濒危物种，它有着吸引人的特质，受到了世界上很多人的喜爱。"

**首届中国大熊猫国际文化周**

2018年8月23日，主题为“熊猫文化·世界共享”的“首届中国大熊猫国际文化周”在北京中华世纪坛开幕。

此次文化周活动旨在进一步研究探讨关于大熊猫的生态保护和文化建设等课题，将“坚持人与世界共生共存的理念，共同营造和谐宜居的人类家园”精神内涵有机融入大熊猫文化，推动大熊猫文化走向世界。

此次文化周涵盖了“大熊猫保护研究成果主题展”“大熊猫文化艺术展”“大熊猫文化彩灯展”等展览，围绕“大熊猫生态历史文化”“大熊猫保护研究文化”“大熊猫国际交流文化”和“大熊猫公益关爱文化”等四个方面取得的保护研究成果，倡导“爱熊猫、爱自然、爱生活”，通过图片、影视、VR虚拟现实、塑化标本、科研展品、艺术作品和中华彩灯等载体，多层面多角度讲述熊猫故事，传播熊猫文化，展现人与自然和谐共生理念。

在此期间，首届中国大熊猫国际文化周系列主题日活动也将同步展开，“熊猫中国·四川主题日”活动、“熊猫中国·陕西主题日”活动、“熊猫中国·甘肃主题日”活动都将组织展演与大熊猫相关的富有各自特色的民俗风情、文化创意产品及美食等内容。
