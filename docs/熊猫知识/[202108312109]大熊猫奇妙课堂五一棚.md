# 大熊猫奇妙课堂 | 五一棚

大

**五一棚**

20世纪70年代，科学家们在海拔2520米  卧龙自然保护区臭水沟一带搭建几顶窝棚，  建立了世界上  第一个大熊猫野外  生态  观察站
开始了世界上最早的野外大熊猫研究工作，因为观察站的帐篷距离水源地有51步台阶，于是取名“五一棚”。

**五一棚的选址与环境**

卧龙自然保护区位于青藏高原向四川盆地的过渡地带，面积20万公顷。从地图上看，它像一片横陈的枫叶，正河、皮条河和西河像三根叶脉横贯东西。从沟口海拔不足1200米的木江坪，到保护区的最高峰——海拔6250米的四姑娘山，直线距离不过50千米，海拔高度却相差5000多米。

复杂的地形、气候、土壤和水文条件，给种类繁多的植物提供了良好的生存环境。4000多种植物呈典型的带谱分布。珙桐、连香树、水青树等中国一类保护植物是这里最古老的的居民。

保护区内有各种兽类96种、鸟类230余种、爬行动物类20种、两栖动物类14种、鱼类6种。包括大熊猫、金丝猴、羚牛、白唇鹿、雪豹、绿尾虹雉、红腹角雉等，其中有30种属于中国一、二类保护动物。大约有150只野生大熊猫生活在这片神秘的山林里。

**五一棚的历史**

五一棚初建时仅由6个大小不同的帆布帐篷组成，1984年后逐步改造成活动房。1986年前棚内一直是用煤油照明，捡朽柴做饭，再加上几张木头钉的简易床，无任何文化娱乐设施，一切生活用品均由人力背上山，生活条件极为艰苦。

五一棚四周，大树参天，竹林丰茂，是野生大熊猫的核心栖息地，
当时大约有18只野生大熊猫生活在这个区域。中外专家在五一棚附近，先后捕捉到“珍珍”、“龙龙”、“宁宁”、“憨憨”、“威威”和“貔貅”等6只不同年龄段的大熊猫。

除大熊猫外，还能见到金丝猴、牛羚、小熊猫等野生动物成群活动。

20世纪80年代，五一棚已成为享誉中外的“帐篷学校”。中国各个大熊猫保护区均派员前往五一棚，与中外专家一起“摸爬滚打”，学习交流，经受风雪与艰苦生活的考验。

通过长期的野外调查分析，他们已探索出野生大熊猫的活动规律、食物特性、种群动态及繁殖习性，完成了《卧龙的大熊猫》、《大熊猫、金丝猴、牛羚》等14部论著，发表科研论文30多篇。这些论著和论文有的已处于国际领先水平。其中《卧龙的大熊猫》一书已翻译成多种文字。

他们长期的研究和探索，揭开了野生大熊猫的生活奥秘，为进一步保护好国宝大熊猫提供了理论依据。五一棚这块最早的大熊猫的野外科研基地，已同大熊猫一起蜚声中外。

中国的最早的大熊猫科研保护事业从五一棚开始，从“学西方、追西方、赶西方”，到现在已成为世界的领头羊。

**现在的五一棚**

五一棚经过了70年代的兴起、80年代的辉煌、90年代的持续和21世纪的更新，当年一个小小的帐篷，如今已经发展成一个有着一套完备设施的工作站。

距离五一棚不远的英雄沟，是熊猫中心最早的饲养场，主要用于野外救护和饲养老、弱、病、残的大熊猫。

五一棚见证了一代又一代大熊猫科研保护人员的努力与成果，是中国大熊猫保护研究事业上一块重要的基石。
