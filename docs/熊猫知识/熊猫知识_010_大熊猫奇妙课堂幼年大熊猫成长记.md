# 大熊猫奇妙课堂 | 幼年大熊猫成长记

**幼年大熊猫成长记**

**大熊猫幼仔的出生**

伴随着大熊猫妈妈为时4-5个月的艰难怀孕时期结束，大熊猫幼仔终于要呱呱落地了，生产的过程大概要持续2-20小时。刚出生的大熊猫幼仔体重很小，只有150克左右，几乎没有视力和听力，但是它们的尖叫声会很大，大熊猫妈妈都是通过声音找到它们的。

2月龄之前的幼仔几乎没有任何活动能力，大熊猫妈妈这段时间内会寸步不离地守在幼仔旁边。因为幼仔在不具备听力和视力的时候只能依靠触觉、嗅觉及叫声和妈妈交流，所以妈妈要时刻通过叫声来判断幼仔的情况。当幼仔发出尖叫时代表它感觉到寒冷，妈妈会立刻调整姿势保证它被自己遮挡住了；当幼仔呱呱叫时代表它感觉很舒服，妈妈会一直保持这个体位；当幼仔连续尖叫时代表它饿了，需要妈妈喂食母乳，幼仔在降生两小时后就会需要吸取初乳，这对幼仔的正常成长非常重要。大熊猫的初乳呈淡绿色，像竹叶的汁液，这也许和它们喜食竹子有关系。

成年大熊猫很容易分辨出性别，但是幼仔的性别分辨可不简单，最直截了当的办法就是依据外露生殖器官的形态来识别。在20日龄之后的雄性大熊猫幼仔的睾丸会逐渐发育长大，这时只要用手指触诊两侧鼠蹊部就能辨别出它是不是雄性了。

**大熊猫幼仔的行为**

对大熊猫幼仔来说最重要的事情就是吸取乳汁，刚出生时它们每天约吸乳十余次，总量在15毫升左右。3个月后，它们的胃口大了一次可以吃100-300毫升，每天进食次数也少了，只要一至两次就够了。而它们最喜欢的竹子，要到半岁左右才会开始学着吃。

在大熊猫幼仔2月龄之后就可以自己爬动了，但是因为它的四肢还并不协调，所以爬行距离并不长。到4月龄左右才算是真正能够走动，像所有动物的幼仔一样，刚学会走路总是不稳定的，时常会翻滚在地，这也很符合它们“滚滚”的外号呢。要等幼仔的四肢力量均衡后，它们才会离开妈妈一段距离，不过出于保护幼仔的天性，妈妈会将好动的幼仔叼回自己身边，这是为了避免幼仔受到意外伤害。

伴随着幼仔的成长，妈妈会教会它们许多本领，如躲避天敌、爬树、选择适口的竹子、寻找水源等。其中爬树也是幼仔们很喜欢的一种活动，当它们学会爬树之后就会经常待在树上了，晒太阳、打盹、玩耍都能在树上进行。

**大熊猫幼仔的生长变化**

刚出生的大熊猫幼仔身体呈浅肉红色，眼睛紧闭，全身只有一些稀疏的白色胎毛，尾巴较长，和成年大熊猫的外貌有些很大的区别，但是大熊猫的生长发育速度很快，特别是体貌表现上。

哺乳一周后，稀疏的被毛会变密变长，肩带、四肢和耳朵渐渐变黑，发育到一月时，身上的被毛已经黑白分明了，和成年大熊猫的被毛接近，但直到44日龄胎毛才会脱落。

大概两周的时候开始长乳牙，一岁时乳牙长齐，三到四岁长出恒牙。

幼仔虽然出生体重就很低，但出生后的前3天因为失水以及不适应的原因，它们的体重会比刚出生还低，从第5天开始增长，增长速度非常快。1月龄时体重会达到1.2千克左右，约为出生时的10倍。此后，第一个月每日平均增重约36克，第2个月至第6个月品滚增重为74-80克。一直生长到约3岁时，就已经和成年大熊猫没有差别了。
