# 大熊猫奇妙课堂 | 走近大熊猫

**走近大熊猫**

**大熊猫的分类**

大熊猫是由始熊的一支演化成始熊猫，再由始熊猫演化成现在的大熊猫。由于它似熊非熊的一系列特征，关于它的科属地位，自1869年给它定名时至今，一百多年过去了，争论仍未终止，有待更多的研究。

目前学术界大部分人认同大熊猫属于：动物界（Animalia），脊索动物门（Chordate），哺乳动物纲（Mammalia），肉食目（Carnivora），熊科（Ursidae），大熊猫亚科（Ailuropodinae）。

**你了解大熊猫吗**

大熊猫身体胖软，头部较圆，颈粗，耳朵小，尾巴短，四肢比较粗壮，特别是那一对八字形黑眼圈，仿佛戴着一副墨镜，非常惹人喜爱。大熊猫的祖先是食肉动物，但它们现在主要吃竹子。一只成年的大熊猫每天要吃12-18千克左右的竹子。

但是大熊猫的牙齿和消化道还是保持着食肉动物的样子，所以被划分为了食肉动物。

**野生大熊猫的繁育**

每年的四五月份是野生大熊猫的繁殖季节，大部分雌性大熊猫在怀孕前期就急着寻找树洞或者石穴作为“产房”，它每胎产
1-2个幼崽。如双胞胎出生，大熊猫妈妈通常会忽视或拒绝较弱的一个，这能保证至少一只成活。大熊猫是天生的早产儿，刚出生的大熊猫皮肤是粉红色的，带有稀疏的白毛，平均初生体重只有
120 克左右，约是成年大熊猫的0.1%，1 个月后体重可达 2 千克，3 个月可达 5-6
千克。大熊猫妈妈会把幼年大熊猫搂在怀里，轻轻舔舐。等到幼年野生大熊猫五六个月大时，大熊猫妈妈就开始教它爬树、游泳、洗澡和剥食竹子等本领。大熊猫是独居动物，两到三岁时，幼年野生大熊猫会离开母亲，开始独立生活。

**大熊猫分布情况**

大约在一百万年前，大熊猫曾广泛分布于我国东部、中部的广大地区，并向外延伸到东南亚的越南、泰国、老挝以及缅甸等地。现在留下来的数量很少，成为科学家研究生物进化珍贵的“活化石”。

而现在，大熊猫主要分布在我国的四川、甘肃、陕西的秦岭、岷山、邛崃山、相岭、凉山山系的高山深谷中，
数量十分稀少，它们性情孤僻，喜欢独居，爱吃爱睡，没有固定的居住地点，常常随季节的变化而搬家。春天一般待在海拔 3000
米以上的高山竹林里，夏天迁移到竹枝鲜嫩的阴坡处，秋天搬到 2500 米左右温暖的向阳山坡上，准备度过漫长的寒冬。

**大熊猫有多少**

目前，只有在我国的四川、陕西、甘肃部分地区的深山老林里才能找到它们的身影，截至第四次全国大熊猫调查显示，野生大熊猫数量为 1864 只。截至
2020年底，圈养大熊猫数量已超过600
只。大熊猫经过漫长的历史发展得以生存到今天，足以体现它顽强的生命力，但是它们依然面临着多方不利因素，一方面是人类活动导致栖息地碎片化，从而导致种群分割、近亲繁殖、物种退化；另一方面是受到自身食性、繁殖能力和育幼行为的影响；再加上人为的捕捉猎杀、天敌带来的危害、疾病困扰等外部因素，这些都对大熊猫的生存构成了严重的威胁，使其面临易危的境地。
