# 大熊猫奇妙课堂 | 大熊猫的粪便（青团）

**大熊猫的粪便（青团）**

**大熊猫的粪便长啥样？**

大熊猫粪便被称为“青团”，我们可以看到，大熊猫的“青团”一般情况下是绿色或黄色的，形状为椭圆，里面会掺杂竹子样的残留物，能从中推测出大熊猫吃的食物，也印证了“大熊猫吃什么拉什么”的事实。

由于每只大熊猫吃竹子时的咬节长短不同，所以遗留在它们粪便中的竹节纤维的长短也不尽相同，有时也会因吃的竹子部位不同，而产生不同颜色的粪便。比如，大熊猫吃竹笋后，粪便呈淡黄绿色；吃竹茎后，呈淡绿色；吃竹叶或竹枝后，呈绿色。专家们常根据粪便颜色、残留竹节的长短来判断大熊猫的年龄和健康状况。

**大熊猫的粪便臭吗？**

大熊猫吃竹子的时候，会总是先把竹子掰断，然后把一段竹子咬成几小节，再咀嚼，和人吃甘蔗相似，它们只吸吮竹壁细胞的内含物，消化小部分的半纤维素，不同的是大熊猫不吐出竹渣。

大熊猫体内没有分解纤维素、木质素的酶，加之竹类的营养价值不高，它们只能通过食用大量竹类来维持正常体力。而且，大熊猫的肠子短，竹子在里面停留的时间短，大部分还没来得及消化就排出去了，没有发酵过的竹子，会带着原始的清香味，这就是为什么大熊猫的粪便会带有竹子味清香的原因。但圈养大熊猫除了竹子外，还会进食一些营养丰富的其他食物，经过消化分解，它们的青团可能会带有臭味。

**粪便主要成分是什么？**

大熊猫粪便的主要成分为竹子、竹笋的残渣，由于大熊猫的胃肠功能不太好，只能吸收食物中20%多的养分，所以遗留在粪便中的营养成分较多。加上圈养大熊猫的食物中还添加了不少其它的营养物质，所以粪便中的蛋白质、粗纤维含量高。

**粪便有哪些用途？**

大熊猫的粪便不仅可用作种植农作物的肥料，还能用来造纸。都江堰、卧龙、碧峰峡三大基地的大熊猫的食物残渣、粪便都会被回收利用，通过洗选、蒸煮、高温消毒等环节提炼出植物纤维，用于产纸。在竹子造纸的工艺流程中，有一道工序是堆积材料、降解果糖、获取竹纤维，而这一步已经由大熊猫在消化过程中完成了，因此大熊猫粪便中剩下的纤维可以直接被提取出来。

**粪便研究**

在野外，大熊猫粪便随时有可能被其它动物或者大风大雨破坏，甚至被太阳晒变了形。此前不少科研人员翻山越岭找“青团”，难得找到一块未被破坏的青团，且在发现青团时，一定要“趁热”、“趁新鲜”，不管这块“青团”多难看，都要第一时间拍照、取样。

因为在大熊猫粪便中，可以看到竹节或竹叶的咬节情况和消化吸收情况，能直观地判断大熊猫的大概年龄段，大熊猫粪便中还蕴含着大熊猫种群多样化数据，通过特殊仪器可以测得大熊猫的DNA信息，分析这些DNA信息，就可以了解大熊猫的性别,年龄,亲缘关系，种群数等。
