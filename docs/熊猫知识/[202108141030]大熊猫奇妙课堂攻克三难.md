# 大熊猫奇妙课堂 | 攻克三难

**大熊猫繁育科普知识B（攻克三难）**

圈养大熊猫的繁育是世界性难题。发情难、配种受孕难和育幼成活难，这三大难关制约着整个圈养种群的发展。中国大熊猫保护研究中心从20世纪90年代初开始了“提高圈养大熊猫繁育力的研究”项目攻关，吹响了全面、系统地攻克“三难”的号角。

**圈养大熊猫发情难**

日常观察大熊猫的身体状况是技术人员和饲养人员的职责之一。按照大熊猫的发情规律，大熊猫的发情期一般在每年的12月和来年的5月，主要集中在春季的3-5月。个别大熊猫在更换了生活环境以后，可能会出现秋季发情的现象。在圈养条件下，大熊猫受到食物、生活环境等的限制，摄取营养不平衡，活动空间狭小，生活环境单调，导致体质下降，缺乏活力，从而造成成年大熊猫难以发情。

1、改善生活环境

中国大熊猫保护研究中心在国内率先研究和应用了环境富集技术，为大熊猫创造了多样化的生活环境，改善了生活空间，增加了活动量，大熊猫的活力得到了明显提高。

2、调整营养结构

圈养大熊猫的主食是竹子，通过增加人工配合饲养和果蔬饲料，加强补充微量元素、蛋白质等营养成分，使得圈养大熊猫的营养摄入更全面、均衡。同时采用少吃多餐、增加活动量等方法，有助于强健体魄。除了竹子之外，同时也会给圈养大熊猫提供少量的苹果、胡萝卜等饭后甜点，幼年时期还会提供牛奶。

3、加强发情诱导

发情季节的大熊猫通过做标记的方法传递出求偶的信号。将发情的雌、雄大熊猫放到相邻的圈舍培养感情，同时相互串圈，通过对方留下的气味刺激发情。时机成熟后，工作人员将它们之间的门打开，让它们走到一起完成自然交配。

**圈养大熊猫受孕难**

1、激素检测

雌性大熊猫每年的最佳受孕时间一般只有1-2天。通过综合运用雌激素监测和行为学观察等方法，确定发情大熊猫的最佳配种时间，极大地提高了大熊猫的受孕率。

2、培训种公兽

中国大熊猫保护研究中心建立了完整的种公兽培育技术，使80%的育龄雄性大熊猫能自然交配，使75%育龄雌性大熊猫和50%育龄雄性大熊猫繁殖了后代。用食物进行后肢力量的训练是培训种公兽常用的方法之一，有利于它们在自然交配时一展雄风。

3、完善人工授精技术

除了自然交配，对于无法完成自然交配或自然交配不理想的大熊猫，还辅以人工授精的手段。“双保险”使受孕率极大地提高，增加了圈养大熊猫的遗传多样性。

**圈养大熊猫育幼成活难**

大熊猫一胎一般产1-2只幼仔，单胎和双胞胎的概率各占一半。雌性大熊猫从完成配种到产出幼仔，需3-5个月。大熊猫受精卵形成之后一直在子宫内游荡，直到生育前大约40天才着床开始发育。刚出生的大熊猫幼仔是名副其实的“早产儿”，体重约150克，许多器官都没有发育完全，极难成活。

1、培训母兽带仔

通过对母兽进行培训，让更多初次生产或不会带仔的母兽逐步成为合格的母亲。

2、完善人工育幼技术

大熊猫妈妈生下双胞胎后，大多选择一只，放弃一只，有的甚至一只都不带。为了让每一只出生的大熊猫幼仔都能成活下来，中国大熊猫保护研究中心将被大熊猫妈妈抛弃的幼仔送到人工育幼室辅助以人工育幼的手段，并且创造性地采用了“仿生育幼”的理念，通过模仿母兽育幼环境开展人工育幼。

为了保证每一个幼仔的正常发育，工作人员从产仔母兽那里采集母乳饲喂，并且定期地将育幼室的幼仔与母亲身边的幼仔进行调换，确保每个幼仔都能平等地得到妈妈的哺育。哺育期的大熊猫妈妈一般母性很强，为了保护幼仔，不惜攻击饲养员，无论是采奶，还是换仔，都需要娴熟的经验以及人和大熊猫之间长期培养起来的信任。同时，根据幼仔的消化生理和发育特点，中国大熊猫保护研究中心还成功研制出了人工配方乳。

**攻克圈养大熊猫繁育三难**

目前，中国大熊猫保护研究中心圈养大熊猫种群数量达到330余只，占全球圈养总数的50%以上，创建了世界最大的人工圈养种群，实现圈养种群从数量优先到质量优先的转变和可持续发展，全面攻克了长期制约圈养大熊猫种群发展的繁育中“发情难”、“配种受孕难”及“育幼成活难”三大世界性难关。
