# 大熊猫奇妙课堂 | 圈养大熊猫的食物

**圈养大熊猫的食物**

**人工饲养大熊猫的历史渊源**

大熊猫作为自然界一种现存的早期生物，在我国的饲养历史非常悠久，西汉时，在现今陕西省咸阳市附近的皇家上林苑动物狩猎场中就圈养有较多的大熊猫，这是世界上饲养大熊猫最早的记载。中华人民共和国成立后，成都动物园于1953年开始饲养第一只大熊猫。之后，北京、上海、重庆、福州、昆明、西安也陆续饲养有大熊猫，并成功繁殖。

**圈养大熊猫的主要食物——竹子**

圈养大熊猫可食的竹子达到60~70种之多，但主要是供应亚高山和中低山的平坝竹，比如孝顺竹、黄金间碧竹、巴山木竹、冷箭竹、方竹、华西箭竹、拐棍竹、华桔竹、观音竹等。

**1、圈养大熊猫的竹子采集地**

中国大熊猫保护研究中心一般是在岷山山系和邛崃山山系采集，种类包括箭竹、方竹、木竹、玉山竹、刚竹、拐棍竹、巴山木竹、白夹竹等。北京动物园就近采集的是刚竹。

**2、投喂大熊猫竹子的总量**

每日投喂竹子的总量要根据大熊猫的大小和食量而定，经测算，大熊猫食竹量大概为其体重的6%~15%，一般每只成年大熊猫需要准备20~30千克竹子，一天分为5~6次投喂，包括夜间。一只成年大熊猫要食入10~15千克竹子，一半以上会浪费掉。研究表明，圈养大熊猫日粮中的竹子投喂量需要超过60%，否则会带来消化不良和频繁排
黏  。

**圈养大熊猫的其他食物**

**1、圈养大熊猫食物营养组成**

除竹子外，还要投喂大熊猫精料。因为圈养大熊猫的食物95%是竹子，人为提供的竹子种类，大熊猫没有选择的余地，为了做到营养全面，必须要投喂一些精料，以补充食物营养成分的不足。精料大多为植物性原料组成，比如小麦、大豆、玉米、大米、麦麸等等。精料大概成分为蛋白质16%~17%，粗脂肪3%~4%，碳水化合物75%。另外，还要投喂一些水果和蔬菜。

**2、圈养大熊猫精料投喂方式**

20世纪60~80年代初期，是按照精料的配方，把很多种类的粮食粉碎、混合后做成流质糊糊喂给大熊猫。将精料以流质糊糊的方式投喂大熊猫，这种方式计量、熬制、保存都比较繁琐，况且不易保存和运送。

20世纪80~90年代改成固体的窝窝头，同样不能储存太久，容易变质。

**3、饲养大熊猫**

**窝窝头、饼干和水果蔬菜**

在给大熊猫添加的窝头或纤维饼干中，一般的构成比例大致为蛋白质18%，粗脂肪4%~5%，碳水化合物75%。精料由小麦、玉米、大米、大豆麦麸、骨粉、竹粉等组成。另外，就是微量元素和维生素。供给大熊猫最普遍的水果是苹果，还有梨、香蕉等;蔬菜主要有胡萝卜、莴苣、藕等。

**4、喂养大熊猫的维生素**

针对不同发育阶段的大熊猫，给予的饲料和添加剂也有所不同。通常添加的矿物元素有钙、镁、钾、铁、锌、锰、铜等:补充的维生素有维生素A、维生素C、维生素E以及B族维生素等。
